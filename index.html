Document Conversion Toolkit

What it does
Lets anyone merge and split PDFs, convert PDF to Word, images to PDF and images to Word, and extract text from scans with OCR, all in the browser.
How it works
A Next.js frontend on Vercel sends files to a FastAPI backend on Railway. The backend runs in Docker, stores data with SQLAlchemy, limits requests per user with Redis, and keeps files in Cloudinary. It runs on a custom domain.
Why it matters
It's a complete product, not just a script: it has a real interface, protection against abuse, and live hosting.

AI Skin Analysis System

What it does
Looks at a face photo and finds wrinkles, acne, blackheads, pores and dark spots, then suggests skincare products.
How it works
Five separate ML models, one per skin concern, run on the photo. A FastAPI backend serves the models, and a web interface shows the results.
Why it matters
It turns several computer vision models into one simple tool that a non-technical person can use.

Customer Churn Prediction

What it does
Predicts which telecom customers are likely to leave, so a company could contact them before they go.
How it works
I explored and cleaned the data, created useful features, encoded categories and scaled numbers, then trained an XGBoost model. A Flask web app gives a prediction in real time.
Why it matters
It covers the full data science cycle, from raw data to a model people can actually use.
